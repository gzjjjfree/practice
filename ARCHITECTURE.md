# Fyne 智能刷题与题库管理客户端 - 架构设计文档

本文档描述了系统的整体架构设计、分层模块划分以及核心运行机制。

---

## 2. 核心模块划分

1. **`main.go`**:
   - 应用入口。初始化全局 `core.AppState`，配置 Fyne 窗口大小与主题，加载初始路由。
2. **`ui/pages/home/`**:
   - 包含主页、登录页、刷题核心逻辑 (`showPractice.go`) 以及各种管理后台界面。
3. **`customElements/`**:
   - 高复用自定义 UI 组件。如 `TouchInterceptor` 负责手机端与桌面端左右滑动翻页及上下滚动。
4. **`parser/`**:
   - 文件解析器。支持通过魔数检测解析 XLSX、带 GBK 编码支持的 TXT 以及 JSON 题库文件。
5. **`network/`**:
   - 基于 `net/http` 封装的 `APIClient`。内置 15 秒超时、LRU 响应缓存、请求去重机制，处理与后端服务器的所有 RESTful 通信。
6. **`storageRelated/`**:
   - 沙盒持久化管理。实现题库安全保存、覆盖确认及影子文件（错题集、收藏集、答题记录）的级联清理。
7. **`export/`**:
   - 支持将做题结果或错题导出为 Excel/PDF/JSON 格式。

---

## 3. 关键设计模式与并发安全

- **全局状态单例 (`core.AppState`)**: 集中管理当前用户令牌、权限、当前题库与刷题状态，确保多界面间状态一致性。
- **线程安全控制**: 刷题记录与网络并发访问均通过 `sync.Mutex` 保护，防止多线程并发冲突。
- **非阻塞 UI 渲染**: 长时间运行的网络请求与文件解析严格异步回调执行，绝不阻塞主 Fyne 渲染线程。
